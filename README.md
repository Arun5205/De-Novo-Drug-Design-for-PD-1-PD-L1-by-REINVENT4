# De-Novo-Drug-Design-for-PD-1-PD-L1-by-REINVENT4
Artificial Intelligence-assisted De Novo Drug Design - Here we used REINVENT4 AI platform to design a new drug molecule for the target PD-1/PD-L1. Finally, we designed 500,000 new drug candidates and filter them by using ML assisted multi-stage virtual screening to identify the potential compounds. After the design and filtration, we identified the top 5 potential compounds for the inhibition of PD-L1 dimer to stop the PD-1/PD-L1 inhibition.
